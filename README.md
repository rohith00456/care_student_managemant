## 📋 About

**CampusVoice** bridges the communication gap between students and college administration. It provides a transparent, structured channel for students to voice concerns, submit reports, and monitor how their feedback is being addressed — promoting accountability and trust within the campus community.

## ✨ Features

- **📝 Submit Feedback** — Report issues across categories like Infrastructure, Academics, Hostel, Mess/Canteen, Administration, and more
- **🔍 Browse & Search Issues** — Filter issues by category, department, status, and urgency
- **📊 Analytics Dashboard** — Visual charts showing resolution rates, recurring issues, and satisfaction metrics
- **🔔 Real-time Status Tracking** — Track issue progress from submission through resolution with detailed timelines
- **👥 Community Support** — Upvote issues that matter to you to help prioritize them
- **🔒 Privacy Controls** — Choose between public, anonymous, or confidential submission modes
- **📱 Fully Responsive** — Works seamlessly on desktop, tablet, and mobile devices
- **🏛️ Transparency Board** — "You Said, We Did" section showing how student feedback translates into action
- **⚡ Single-Page App** — Fast, smooth navigation with no page reloads

## 🚀 Getting Started

### Prerequisites

- Any modern web browser (Chrome, Firefox, Safari, Edge)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/rohith00456/care_student_managemant.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd care_student_managemant
   ```

3. **Open in browser**
   ```bash
   # Simply open the HTML file in your browser
   start campusvoice.html        # Windows
   open campusvoice.html          # macOS
   xdg-open campusvoice.html      # Linux
   ```

   Or use a local server:
   ```bash
   # Using Python
   python -m http.server 8000

   # Using Node.js
   npx serve .
   ```

4. **Visit** `http://localhost:8000/campusvoice.html`
